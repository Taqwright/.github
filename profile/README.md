### What Taqwright does

- **Describe a journey in plain English.** *"Log in, add a dress to the cart, check out."* LIME drives a real
  Android or iOS device and records it as a stable UI test, with locators and no hard-coded coordinates.
- **Fits the suite you already have.** It drops in alongside your existing tests and your own Appium setup.
  Run on local devices or on cloud devices from BrowserStack or TestMu AI (formerly LambdaTest).
- **Lands as a pull request.** A recorded journey becomes a test in your repository and runs in CI like any other.
- **Visual checks included.** AI visual regression catches what an assertion would miss.

### Get started

| Tool | What it is | Install |
|---|---|---|
| **LIME Agent** | Connects the devices on your machine to LIME | `npm install -g @taqwright/lime-agent` |
| **lime-cli** | Turns a goal into a test from your terminal or CI | `npm install -g @taqwright/lime-cli` |
| **LIME console** | Device Lab, reports and scenarios in the browser | [www.taqwright.ai](https://www.taqwright.ai) |
